# Qiaomu Editorial Design Example

This example documents a public `yao-geoflow-design` workflow for mapping a
reference editorial style onto GEOFlow's Laravel Blade theme boundary.

## Purpose

Use this example to review how the design skill:

- studies a reference URL without copying raw HTML
- maps visual direction onto existing GEOFlow modules
- keeps design work preview-first
- separates theme editing from production activation

## Public Safety

The example uses committed preview HTML, CSS, JavaScript, and Markdown reports.
It does not add private customer material, credentials, local absolute paths, or
production activation instructions.

The existing preview predates the self-contained package contract used by
`yao-geoflow-template`. Its optional metadata chip still points to ignored
runtime `outputs/` JSON files. Treat this example as a design workflow and
preview-review example, not as a self-contained package metadata contract.

## Non-Goals

- no live template activation
- no route, SEO, controller, database, or backend query changes
- no claim that the committed preview is production-ready
- no conversion of this design example into a `yao-geoflow-template` package
