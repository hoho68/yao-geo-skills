# 标准交付物清单

这份清单用于告诉自己和客户：一个 GEO / GEOFlow 项目到底交付什么。

## 交付组合 A：无源码诊断

适合：

- 客户只给网站网址
- 客户先想判断值不值得做

交付物：

- [ ] 客户项目资料表
- [ ] 当前网站问题诊断
- [ ] 页面结构分析
- [ ] GEO 内容机会点
- [ ] 参考网站风格分析
- [ ] 初步改造建议
- [ ] 如果要继续，需要客户提供的源码资料清单

客户能得到：

- 知道现在问题在哪里
- 知道下一步怎么做
- 不需要先冒险改网站

## 交付组合 B：参考站风格方案

适合：

- 客户有喜欢的参考网站
- 客户希望把当前网站改得更专业
- 暂时还没有源码

交付物：

- [ ] 参考网站视觉拆解
- [ ] 色彩 / 字体 / 间距 / 卡片风格说明
- [ ] GEOFlow 页面模块映射
- [ ] tokens 方案
- [ ] mapping 方案
- [ ] preview-only 改造建议

客户能得到：

- 明确知道要改成什么风格
- 能把方案交给设计师或开发
- 后续有源码时可以继续做 preview

## 交付组合 C：GEOFlow 源码接入

适合：

- 客户已经提供源码
- 需要判断能不能安全做主题预览

交付物：

- [ ] 源码路径记录
- [ ] Laravel / legacy PHP 判断
- [ ] theme discovery 输出摘要
- [ ] 可编辑主题列表
- [ ] 建议选择的 target theme
- [ ] 是否适合创建 preview edit session
- [ ] 风险提醒

客户能得到：

- 知道源码能不能继续做
- 知道有哪些主题
- 知道第一步改哪里最安全

## 交付组合 D：preview 主题切片

适合：

- discovery 已通过
- 客户允许做预览
- 还不能上线

交付物：

- [ ] preview 主题
- [ ] change-plan.md
- [ ] preview-notes.md
- [ ] tokens.json
- [ ] mapping.json
- [ ] 本次修改说明
- [ ] 验证命令记录
- [ ] 未上线声明

客户能得到：

- 一个可审阅的预览方向
- 知道本次改了什么
- 知道还没有动生产站

## 交付组合 E：上线前准备

适合：

- 客户已经确认 preview
- 准备进入上线讨论

交付物：

- [ ] 上线范围说明
- [ ] 当前生产主题确认
- [ ] 备份方案
- [ ] 回滚方案
- [ ] 上线窗口
- [ ] 客户确认记录
- [ ] 上线后检查清单

客户能得到：

- 知道上线风险
- 知道怎么回滚
- 知道谁负责确认

## 每次交付必须包含的 5 个句子

无论项目大小，每次交付都要写清楚：

```text
1. 本次完成了什么：
2. 本次没有做什么：
3. 本次交付物在哪里：
4. 当前风险是什么：
5. 下一步建议是什么：
```

## 不应该交付给客户的东西

不要交付：

- 没说明边界的代码包
- 没有客户确认的上线结果
- 带密码、`.env`、API Key 的文件
- 没有说明来源的截图
- 无法复查的口头承诺
- 声称 preview-ready 就等于 production-ready 的报告
